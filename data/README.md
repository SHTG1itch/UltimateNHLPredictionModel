# Data directory

`games.csv` is generated by the CLI and intentionally ignored by Git. Each row
is one completed NHL regular-season or playoff game retrieved from the NHL web
API. Keeping raw downloads out of history makes the repository reproducible and
prevents its size from growing toward the hard 10 GB limit.

Generate it with:

```powershell
nhl-predict download --seasons 20212022 20222023 20232024 20242025
```

The downloader requests team season schedules concurrently, deduplicates them
by official game ID, removes preseason games, and sorts by the official UTC
start time. It never imputes game results.
